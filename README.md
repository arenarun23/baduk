# 꼬마 바둑 교실 ⚫⚪

초등학교 1학년 친구가 바둑 규칙을 배우고, 문제로 확인하고, AI 친구와 대국하는 웹 게임입니다.

## 메뉴

- **📚 배우기**: 판다 선생님과 9개 레슨 (바둑판과 돌 → 숨구멍 → 돌 잡기 → 단수 → 도망가기 → 이어진 돌 → 둘 수 없는 곳 → 패 → 따먹기 바둑). 직접 돌을 놓아 보며 배워요.
- **✏️ 문제 풀기**: 숨구멍 세기, 잡기, 단수 치기, 도망가기, 착수 금지(⭕/❌) 12문제. 순서가 섞이고, 결과는 별 3개로 보여 줘요.
- **🎮 AI와 대국**: 따먹기 바둑 (정해진 개수만큼 먼저 잡으면 승리). 바둑판 5·7·9·12·15줄.
  - 🐢 아기 거북이: 거의 아무 데나 둬요.
  - 🐰 깡충 토끼: 잡을 수 있으면 잡고, 단수면 도망가요. 가끔 실수해요.
  - 🐯 용감한 호랑이: 축까지 수읽기를 해요.
  - 힌트, 무르기, 단수 알려 주는 도우미가 있어요.
- 🔊 버튼을 누르면 글을 소리 내어 읽어 줘요. 공부 기록은 브라우저에 저장돼요.
- 🔔 효과음: 돌 놓는 "딱", 잡기 "뿅+반짝", 단수 경고 "삐뽀", 정답 "딩동댕", 별 받기, 승리 팡파르 등. 소리 파일 없이 Web Audio로 만들어요 (`src/lib/sound.ts`). 오른쪽 위 🔔 버튼으로 끌 수 있어요.

## AIEDU 허브

이 앱은 [AIEDU 허브](https://aiedu-pearl.vercel.app)의 `/baduk/` 에서 서비스됩니다.

- 허브는 정적 파일만 가져오므로, `main` 에 push 하면 GitHub Actions(`.github/workflows/hub-build.yml`)가 시험·빌드 후 결과물을 **`hub` 브랜치**에 올리고 허브를 다시 배포합니다. `hub` 브랜치는 직접 고치지 마세요(매번 새로 덮어씀).
- 허브 규칙: 외부 주소 호출 금지(글꼴은 허브의 `../fonts/jua.css`), 상대경로(`vite.config.ts` 의 `base: './'`), 왼쪽 위 허브 복귀 아이콘(`index.html`), 익명 이용 기록(`../aiedu-log.js`, `src/lib/log.ts` — 이벤트 종류와 짧은 태그만), 여러 화면 크기에서 한 화면에 맞추기.
- 허브 밖(이 저장소의 단독 Vercel 배포)에서는 글꼴이 시스템 글꼴로 바뀌고 이용 기록은 보내지 않습니다.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 규칙 엔진, AI, 레슨/문제 정답 검사
npm run build   # dist/ 로 빌드 (Vercel이 자동으로 실행)
```

- `src/engine/go.ts`: 바둑 규칙 (숨구멍, 따내기, 착수 금지, 패)
- `src/engine/ai.ts`: AI 3단계와 수읽기
- `src/data/lessons.ts`, `src/data/quiz.ts`: 레슨과 문제. 판은 글자로 그려요
  (`X` 흑, `O` 백, `x`/`o` 눈여겨볼 돌, `?` 눈여겨볼 빈칸, `L` 숨구멍, `N` 둘 수 없음, `T` 별).
  정답은 엔진이 계산하므로 문제를 추가하면 `npm test`가 풀 수 있는지 검사해요.

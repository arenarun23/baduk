# 꼬마 바둑 교실 ⚫⚪

초등학교 1학년 친구가 바둑 규칙을 배우고, 문제로 확인하고, AI 친구와 대국하는 웹 게임입니다.

## 메뉴

- **📚 배우기**: 판다 선생님과 9개 레슨 (바둑판과 돌 → 숨구멍 → 돌 잡기 → 단수 → 도망가기 → 이어진 돌 → 둘 수 없는 곳 → 패 → 따먹기 바둑). 직접 돌을 놓아 보며 배워요.
- **✏️ 문제 풀기**: 숨구멍 세기, 잡기, 단수 치기, 도망가기, 착수 금지(⭕/❌) 12문제. 순서가 섞이고, 결과는 별 3개로 보여 줘요.
- **🎮 AI와 대국**: 따먹기 바둑 (정해진 개수만큼 먼저 잡으면 승리). 5·7·9줄 판.
  - 🐢 아기 거북이: 거의 아무 데나 둬요.
  - 🐰 깡충 토끼: 잡을 수 있으면 잡고, 단수면 도망가요. 가끔 실수해요.
  - 🐯 용감한 호랑이: 축까지 수읽기를 해요.
  - 힌트, 무르기, 단수 알려 주는 도우미가 있어요.
- 🔊 버튼을 누르면 글을 소리 내어 읽어 줘요. 공부 기록은 브라우저에 저장돼요.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 규칙 엔진, AI, 레슨/문제 정답 검사
npm run build   # dist/ 로 빌드 (Vercel이 자동으로 실행)
```

- `src/engine/go.ts`: 바둑 규칙 (숨구멍, 따내기, 착수 금지, 패)
- `src/engine/ai.ts`: AI 3단계와 수읽기
- `src/data/lessons.ts`, `src/data/quiz.ts`: 레슨과 문제. 판은 글자로 그려요
  (`X` 흑, `O` 백, `x`/`o` 눈여겨볼 돌, `?` 눈여겨볼 빈칸, `L` 숨구멍, `N` 둘 수 없음, `T` 별).
  정답은 엔진이 계산하므로 문제를 추가하면 `npm test`가 풀 수 있는지 검사해요.
